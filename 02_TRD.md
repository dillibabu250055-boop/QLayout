# 02_TRD.md

## Architecture Overview
Lightweight, rapid-prototyping stack optimized for a 36-hour hackathon. Avoid unnecessary microservices or heavy frameworks.

## Technology Choices
- **Frontend / UI:** Streamlit
- **Application Logic:** Python 3.10+
- **Numerical Computing:** NumPy, SciPy
- **Graph & Connectivity:** NetworkX (strictly for representing quantum circuit topology and routing graphs)
- **Visualization:** Plotly, Matplotlib
- **Data Persistence:** JSON (file-based)
- **Optimization:** Custom Python heuristic optimizer (Hill Climbing)

## Strict Constraints
Do not introduce React, Next.js, FastAPI, PostgreSQL, Docker, or Kubernetes.
